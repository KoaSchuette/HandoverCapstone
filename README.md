# Collaborative Robotic Tool Handover System

Welcome! This is the capstone project of MREN 403 Group 16 at Queen's University (Smith Engineering).

We built a collaborative robot assistant for a manufacturing work cell. Working beside an operator at a workbench, a UR5e arm takes a spoken request for a screwdriver, picks it off a tool rack with an electromagnetic end effector, and hands it to the operator. When the operator puts a tool down in the return zone, the robot picks it up and returns it to the rack.

This repository holds the ROS 2 workspace (`src/`) and the engineering portfolio that documents it.
